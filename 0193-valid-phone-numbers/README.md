<h2><a href="https://leetcode.com/problems/valid-phone-numbers/">193. Valid Phone Numbers</a></h2><h3>Easy</h3><hr><p>Given a text file <code>file.txt</code> that contains a list of phone numbers (one per line), write a one-liner bash script to print all valid phone numbers.</p>

<p>A phone number is valid if it matches one of the following formats:</p>
<ul>
  <li><code>(xxx) xxx-xxxx</code></li>
  <li><code>xxx-xxx-xxxx</code></li>
</ul>

<p>You may assume that there will not be any leading or trailing white space, but there may be other characters (non-digits) in the file.</p>

<p><strong>Example:</strong></p>
<p>Assume that <code>file.txt</code> has the following content:</p>
<pre>
987-123-4567
123 456-7890
(123) 456-7890
</pre>

<p>Your script should output the following valid phone numbers:</p>
<pre>
987-123-4567
(123) 456-7890
</pre>

<p><strong>Topics:</strong> Shell</p>
