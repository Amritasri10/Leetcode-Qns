<h2><a href="https://leetcode.com/problems/transpose-file/">194. Transpose File</a></h2><h3>Medium</h3><hr><p>Given a text file <code>file.txt</code>, transpose its content.</p>

<p>You may assume that each row has the same number of columns, and each field is separated by the <code>' '</code> character.</p>

<p><strong>Example:</strong></p>
<p>If <code>file.txt</code> has the following content:</p>
<pre>
name age
alice 21
ryan 30
</pre>

<p>Output the following:</p>
<pre>
name alice ryan
age 21 30
</pre>

<p><strong>Topics:</strong> Shell</p>
